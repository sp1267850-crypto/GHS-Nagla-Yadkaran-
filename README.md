# GHS-Nagla-Yadkaran-
राजकीय हाई स्कूल नगला यादकरन विद्यार्थियों को गुणवत्तापूर्ण शिक्षा, अनुशासन और संस्कार प्रदान करने वाला विद्यालय है। यहाँ कक्षा 9वीं एवं 10वीं के साथ स्मार्ट क्लास, कंप्यूटर लैब, विज्ञान प्रयोगशाला, पुस्तकालय, खेल, योग और अन्य सुविधाएँ उपलब्ध हैं। हमारा उद्देश्य विद्यार्थियों के उज्ज्वल भविष्य का निर्माण करना है।
